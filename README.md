# Raksha Bandhan • Sacred Digital Sanctuary

An authentic, reverent, and interactive digital Raksha Bandhan celebration built with Astro, Cloudflare, and native WebCrypto.

## Features
- **Traditional Shravana Purnima Muhurat Clock**: Live astrological countdown, Choghadiya auspicious windows, and Bhadra Kaal status with Bengali & English numerals.
- **Interactive Puja Thali & Live Altar**: 5-step Vedic Puja ceremony (Deepa Prajvalana, Aarti Parikrama with temple bells, Chandan-Tilak, Mithai Arpan, and Raksha Bandhan).
- **Custom Rakhi Studio**: Design consecrated Rakhi sutras with Vedic motifs (Om, Swastika, Kundan, Rudraksha) and download high-resolution keepsakes.
- **Dedicated Sibling Sanctuary for Promi**: Personalized letter, curated memories gallery, return wishes, and bespoke promises.
- **Zero-Knowledge Encrypted Capsule**: End-to-end encrypted private sibling letters using native WebCrypto (AES-256-GCM + PBKDF2) with compact stream deflation.
- **Sibling SLA (Raksha Sankalpa Pratigya Patra)**: Interactive legal deed with digital signature canvas and PNG export.
- **Full Bilingual Localization**: Seamless English and Bengali (বাংলা) language switching with Bengali default.

## Tech Stack
- **Framework**: Astro 5 (Server Output on Cloudflare)
- **Styling**: Vanilla CSS (Vedic Light Theme - Sandalwood, Ivory, Saffron, Kumkum Gold)
- **Audio**: Web Audio Synthesizer (Temple bells, Shankha resonance, Tanpura drone)
- **Cryptography**: WebCrypto API (AES-256-GCM + PBKDF2) + Deflate Stream Compression

## Getting Started

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
